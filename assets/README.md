# Assets - Agendei Landing

## Imagens Necessárias

### agendei-dashboard.png
- **Localização esperada**: `assets/agendei-dashboard.png`
- **Tamanho recomendado**: 1200px × 800px (ou maior em 2x)
- **Formato**: PNG com fundo transparente
- **Uso**: Hero section mockup do dashboard
- **Descrição**: Screenshot do dashboard principal do Agendei mostrando a interface dark com widgets de dados, agenda e ações rápidas

## Como adicionar

1. Salve a imagem do dashboard como `agendei-dashboard.png`
2. Coloque nesta pasta (`assets/`)
3. A imagem será automaticamente carregada no hero mockup
